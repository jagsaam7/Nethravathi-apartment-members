Users

Admin: full edit access, can create Supervisor and Viewer accounts below. Supervisor: can view this section, no edits/add/remove. Viewer: a guest-level account — locked directory view only (same reach as a signed-out guest), no admin section access. Give this role to residents/security who should only browse the directory. Every account type's flat-detail views (Admin, Supervisor, Viewer, and anonymous Guest) are recorded in the Access Log tab.

Access Log

↻ Refresh 🗑️ Clear Log

Tracks every time a flat's member details (name, Mobile 1, Mobile 2) were opened — by Admins, Supervisors, Viewer-role accounts, and anonymous signed-out guests. Guests must verify a mobile number with a 6-digit OTP before they can browse the directory at all, and are then logged under that mobile number (instead of a generic "Guest" label) so every flat they view is traceable. Shows the flat number, who viewed it, their role, and the exact time. Entries auto-clear after 24 hours.

📥 Bulk Import Flats / Owners / Tenants

Paste a JSON array to create new flats in one go — each item is {"block":"A","flatNumber":"001","owner":{"name":"...","mobile1":"...","mobile2":"..."},"tenant":{"name":"...","mobile1":"...","mobile2":"..."}} (omit tenant for owner-occupied flats; mobile2 may be null). Flats whose block + flat number already exist are skipped automatically, so this is safe to re-run with an updated sheet later.

📊 Bulk Import Dues / Payments

Paste a JSON array to load monthly BWSSB / water bill / car charge records — each item is {"block":"A","flatNumber":"001","month":"August","bwssbStatus":"paid","bwssbAmount":10000,"waterBill":800,"carCharge":300}. bwssbStatus is one of paid, pending, not_recorded. The flat must already exist (import flats first). Re-running for a month you've already loaded creates duplicate rows for that month — edit or delete individual entries from the Dues tab instead.
